SiliconRE 315-5242 reference

This directory preserves the SiliconRE M71064 Verilog used only as a
verification oracle. It is not instantiated by the production core.

Source: https://github.com/furrtek/SiliconRE/tree/master/Sega/315-5242
Author: Sean "furrtek" Gonsalves
Purpose: silicon-traced RGB latch, blanking, grayscale and shade-control
reference for the Sega 315-5242 video DAC module.

The original SiliconRE repository is GPL-2.0. Keep this reference separate
from synthesizable production RTL and preserve the upstream attribution when
redistributing it.
